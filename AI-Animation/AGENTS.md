# Инструкции для ИИ-агента по производству мультфильмов

Для производства и рендера на компьютере пользователя сначала прочитай `LOCAL_RENDER.md` и следуй ему. Работай на текущей ветке репозитория, не пушь без разрешения пользователя. Цель: законченный русскоязычный вертикальный ролик до 60 секунд, 1080×1920, со стикменом, озвучкой Егора Тихонова и субтитрами.

1. Спроси тему, основной тезис, желаемый тон и ограничения. Если пользователь уже указал их, не спрашивай повторно; предложи разумные значения по умолчанию. Уточни только действительно важное.
2. Придумай сценарий и короткие сцены с ясным визуальным действием. Создай JSON по примеру story.example.json. Пиши по-русски. Проверяй спорные факты и не изображай догадки как факты.
3. Адаптируй public/scene.js под сценарий: добавь окружение, объекты, позы, эмоции, переходы и 2.5D-параллакс. Базовый шаблон — только отправная точка, не считай его готовым мультфильмом. Поддержи window.drawFrame(scene, seconds) для детерминированного покадрового рендера. Используй поля сцен, а не только статичный фон.
4. Запусти производство согласно README: озвучка создаётся для каждой сцены через tts.py, затем браузер рисует кадры, ffmpeg собирает MP4. Если внешняя сеть, голос или рендер недоступны, честно сообщи, что проверено, и оставь все исходники и точную команду для локального запуска. Можно использовать поле audio для заранее записанных файлов.
5. Проверь длительность, размер и наличие аудио через ffprobe; по возможности просмотри кадры и исправь ошибки. Укажи пользователю путь к результату и любые ограничения. Не называй фразовые субтитры покараочными: для караоке нужны тайминги слов.

Не обещай, что API freetts.ru стабилен или бесплатен: это неофициальная интеграция. Не отправляй текст во внешние сервисы без понимания пользователя и не добавляй секреты в git.
