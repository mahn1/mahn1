# AI Animation

Заготовка для ИИ-агента: пользователь описывает идею, агент уточняет детали, пишет сценарий, адаптирует Three.js-сцену и собирает вертикальный MP4. Инструкции агенту — в `AGENTS.md`, подробный порядок локального производства и рендера — в `LOCAL_RENDER.md`. Это не автономная нейросеть: нужен отдельный AI coding agent с доступом к файлам и запуску команд. Стартовая сцена демонстрационная; под каждый сюжет агенту нужно дорабатывать графику и анимацию. Субтитры пока по фразам, не покараочные.

## Установка

Нужны Python 3.10+, Node.js 20+, ffmpeg и ffprobe в PATH. В каталоге проекта:

```sh
python3 -m pip install -r requirements.txt
npm install
npx playwright install chromium
```

На Linux для Chromium могут понадобиться системные библиотеки (`npx playwright install-deps chromium`, потребуются права администратора). Озвучка требует доступа к `api.freetts.ru`; используется неофициальный протокол, сервис может изменить его или отказать в запросе.

## Озвучка

```sh
python3 tts.py --list
python3 tts.py --voice 'Егор Тихонов' --text 'Привет! Это мой мультфильм.' --output voice.mp3
python3 tts.py --voice 24 --text 'Привет!' --output voice.mp3
```

Номер — позиция в актуальном списке API и может измениться; для надёжности используйте имя или ID. Некоторые голоса могут быть платными. При импорте доступна `tts(voice, text, output_path='output.mp3', lang='rus')`.

## Производство

Попросите подключённого к репозиторию кодового ИИ: «Создай мультфильм по инструкциям AGENTS.md». Он задаст нужные вопросы и изменит сценарий и сцену. Пример формата — `story.example.json`; `text` это и речь, и субтитр, `emotion` и остальные поля можно использовать в собственном коде сцены.

```sh
npm run render -- story.example.json output.mp4
```

Рендер происходит покадрово: 1080×1920, 30 кадров/с, H.264/AAC; длительность определяется озвучкой и ограничена минутой. Кадры хранятся в `.render/` и могут занимать много места; они перезаписываются при следующем запуске. Чтобы обойти TTS, укажите у каждой сцены `"audio": "путь/к/файлу.mp3"` относительно JSON. Пример использует одинаковый морской фон; поле `background` пока не обрабатывается. Прогресс печатается каждые 150 кадров. Рендер может быть очень медленным без GPU.
