# Вымышленная история об авиакатастрофе

Сценарий `story.plane.json` состоит из шести сцен: полёт, гроза, кабина, снижение, удар о воду, спасатели. Это не описание реального рейса. Сцена `public/scene.js` предназначена именно для этой истории. Субтитры выводятся по фразам, а не по словам.

На компьютере с установленными зависимостями, ffmpeg, ffprobe и браузером Playwright выполните из папки `AI-Animation`:

```sh
npm run render -- story.plane.json plane.mp4
```

Для озвучки используется Егор Тихонов на неофициальном API FreeTTS.ru; требуется интернет и доступность голоса. Озвучка и полная сборка в среде подготовки не проверены: соединение с FreeTTS ограничено, ffmpeg и ffprobe недоступны. После рендера проверьте длительность (не более 60 секунд), изображение, звук и субтитры. Дополнительные инструкции: `LOCAL_RENDER.md`.
