# Elisa

Elisa — настольный помощник для Windows. Окно написано на C# (Windows Forms), интерфейс React работает через Microsoft Edge WebView2. Ответы и вызовы инструментов поступают от выбранной модели OpenRouter.

## Подключение и использование

1. Запустите `Elisa.exe`, откройте настройки (кнопка с ползунками).
2. Вставьте свой API-ключ OpenRouter и укажите **точный ID модели**. Начальное значение `openrouter/free` выбирает бесплатную модель автоматически. Для работы агента выбранная модель должна поддерживать tool calling; доступность бесплатных моделей и лимиты меняются. Платные модели могут расходовать баланс.
3. Напишите задачу в чате. Если модель предложит выполнить действие, Elisa покажет полный скрипт PowerShell в отдельном окне Windows. Прочитайте его целиком и выберите «Выполнить» или «Отклонить». По умолчанию и по Enter выбирается отказ.

Ключ хранится только в оперативной памяти до закрытия приложения; при следующем запуске его нужно ввести заново. Диалоги тоже существуют только в течение текущего запуска. Сообщения, результаты команд и содержимое файлов, которое возвращает команда, отправляются в OpenRouter и выбранному провайдеру модели. Не отправляйте секретные данные, если не готовы к этому. Не сообщайте API-ключи в чате.

## Доступ к Windows и безопасность

- Подтверждённые команды запускаются **без песочницы** и имеют права текущего пользователя: могут читать, менять и удалять файлы, запускать программы и обращаться к сети. Права администратора автоматически не выдаются. Запуск приложения от администратора даст командам соответствующие права; не делайте этого без необходимости.
- Проверяйте всю команду, включая сетевые операции и скрытые последствия, перед подтверждением. Содержимое файлов и вывод программ могут содержать вредоносные инструкции для модели; не разрешайте действие только потому, что его предложила модель.
- Есть ограничение в 12 вызовов инструмента за запрос, 60 секунд на одну команду и 24 000 символов на каждый поток вывода. С помощью кнопки остановки можно прервать запрос или выполняемую команду. Уже выполненные изменения не откатываются. Отдельно запущенные процессы могут продолжить работу.
- Если запрос прерван или возникла ошибка после выполнения команды, её результат виден в интерфейсе, но незавершённый ход не сохраняется в контексте модели. При продолжении расскажите модели, что уже выполнено.

## Сборка EXE в Windows

Для сборки на Windows x64 нужны [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0), [Node.js](https://nodejs.org/) 20.19+ или 22.12+ с npm и интернет для npm и NuGet.

Откройте `build.bat` или выполните в PowerShell из папки проекта:

```powershell
.\build.bat
```

Готовый файл — `build\Elisa\Elisa.exe`. Копируйте **всю папку `build\Elisa`**, включая `wwwroot`. Сборка включает .NET Runtime; для запуска нужен также [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (обычно уже установлен в Windows 11).

Для разработки интерфейса выполните `npm install` и `npm run dev`. В браузере доступен только просмотр интерфейса: агент и ключ работают исключительно в Windows-приложении.

## Сборка на GitHub

При каждом push GitHub Actions собирает приложение на Windows. После успешного выполнения откройте вкладку **Actions**, выберите запуск **Build Elisa for Windows** и скачайте артефакт `Elisa-Windows-x64`. Распакуйте его целиком и запустите `Elisa.exe`. Логотип Elisa: `assets/elisa-logo.svg` и `Elisa.Desktop/elisa.ico`.
