# Elisa

Elisa — демонстрационный интерфейс настольного чата в чёрно-зелёной гамме. Окно написано на C# (Windows Forms) и показывает интерфейс React через Microsoft Edge WebView2. Логотип Elisa создан для этого проекта: исходный вектор — `assets/elisa-logo.svg`, значок приложения — `Elisa.Desktop/elisa.ico`.

## Сборка EXE в Windows

Для сборки на Windows x64 нужны:

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (именно SDK, не только Runtime);
- [Node.js](https://nodejs.org/) 20.19+ или 22.12+ и npm;
- интернет для загрузки npm- и NuGet-зависимостей.

Откройте `build.bat` двойным щелчком или выполните в PowerShell в папке проекта:

```powershell
.\build.bat
```

Готовое приложение находится в `build\Elisa\Elisa.exe`. Для переноса копируйте **всю папку `build\Elisa`**, включая `wwwroot`: EXE загружает из неё интерфейс. Сборка включает .NET Runtime, поэтому отдельно устанавливать .NET на компьютере для запуска не нужно. Нужен установленный [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (обычно уже есть в Windows 11).

## Для разработки интерфейса

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет терминал. `npm run build` проверяет сборку интерфейса отдельно.

## Что работает сейчас

Это **только интерфейс**: навигация, демо-диалоги, поиск, выбор модели и настройки. OpenRouter и исполнение команд не подключены, API-ключи не вводятся и не сохраняются, реальные ответы от моделей не приходят. Список моделей приведён для примера. Данные демо-чатов хранятся только в памяти страницы и сбрасываются после перезапуска или обновления.

## Сборка на GitHub

При каждом push GitHub Actions собирает приложение на Windows. После успешного выполнения откройте вкладку **Actions**, выберите запуск **Build Elisa for Windows** и скачайте артефакт `Elisa-Windows-x64`. Распакуйте его целиком и запустите `Elisa.exe`.
