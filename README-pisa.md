# 🏛️ Пизанская башня — тестовая Remotion-анимация

Вертикальный ролик 1080×1920 (9:16), 30 fps, 36 секунд, **русские субтитры по словам**.
Вся графика — векторная (React + SVG), без стоковых картинок: толстые контуры,
два оттенка на объект, плоская «мультяшная» сцена как в референсах.

## Что внутри

| Сцена | Кадры | Что происходит |
|---|---|---|
| 1. Стройка | 0–292 | Башня «вырастает» по ярусам, рабочие с молотком |
| 2. Наклон | 292–424 | Башня кренится, человечки ахают |
| 3. Крупный план | 424–524 | Камера наезжает на крен |
| 4. Грунт в разрезе | 524–632 | Видно глину и водоносный слой под башней |
| 5. Просадка | 632–752 | Башня уходит в землю, идут трещины |
| 6. Падение | 752–860 | Башня заваливается, пыль, табличка «ЗАКРЫТО» |
| 7. Туристы | 860–976 | Люди прыгают и радуются |
| 8. Тросы | 976–1080 | Инженеры тянут башню обратно + финальная заставка |

Свет за это время плавно переходит из дня в закат.

## Стек

- **Remotion 4** (React → видео, кадр за кадром)
- **React 19 + TypeScript**, графика на инлайновом SVG
- **Montserrat** (900) с кириллицей — подключена локально через `@remotion/fonts`
- **@remotion/player + Vite** — живой предпросмотр в браузере

## Запуск

```bash
npm install

npm run dev        # плеер в браузере: http://localhost:5173
npm run studio     # Remotion Studio (таймлайн, отладка кадров)
npm run render     # MP4 → out/pisa-ru.mp4
npm run still      # один кадр → out/frame.png
```

## Где что лежит

```
src/
├── Root.tsx                 # композиция PisaRu + загрузка шрифтов
├── Video.tsx                # тайминг, сцены, камера, эффекты
├── theme.tsx                # размеры, палитра, стиль субтитров
├── fonts.ts                 # подключение Montserrat (кириллица)
├── components/
│   ├── Backdrop.tsx         # небо, солнце, облака, холмы, трава, дорожка
│   ├── Person.tsx           # человечки (шапка/каска/молоток, ходьба)
│   └── Caption.tsx          # русские субтитры по словам
├── world/
│   ├── Tower.tsx            # башня: 7 ярусов, аркады, наклон, «рост»
│   └── palette.ts           # палитра день → закат, длительность
└── player/main.tsx          # браузерный плеер (Vite)
```

## Как поменять текст

Все субтитры собраны в одном месте — `Captions` в `src/Video.tsx`:

```tsx
...makePhrase(146, 236, 'Но грунт оказался', 2),   // [начало, конец) в кадрах, текст, слов в строке
...makePhrase(236, 292, 'слишком мягким', 2),
```

`makePhrase(from, to, text, wordsPerLine)` сам разбивает фразу на короткие
«кадры» по 2–3 слова и раздаёт им тайминг — на экране никогда не висит
целая длинная строка.

## Рендер без интернета

В песочнице Remotion не может скачать свой Chrome, поэтому он берётся из
`@sparticuz/chromium`, а недостающие библиотеки (NSS/NSPR) — из его же
`al2023.tar.br`. Скрипт делает это автоматически:

```bash
node scripts/render-local.mjs          # MP4
node scripts/render-local.mjs still 300 # один кадр
```
